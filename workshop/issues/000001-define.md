# define — NOAD word lookup with Google-style IPA and spoken pronunciation

## Problem

Looking up a word today means opening a browser, typing "define X", and reading
Google's dictionary panel. That panel is worth reproducing in the terminal: it
carries the New Oxford American Dictionary (NOAD) entry, NOAD's distinctive
pronunciation notation (`/ˌsikəˈfan(t)ik/` — `i` for /ɪ/, `a` for /æ/, `(t)`
for the optional flap), and a recorded Oxford pronunciation.

Both halves are reachable without scraping and without an API key:

- **NOAD ships with macOS.** `New Oxford American Dictionary.dictionary` is on
  disk, and `DCSCopyTextDefinition` (public, in the CoreServices SDK header
  `DictionaryServices.h`) returns its entry as flat text. Verified: it returns
  `ˌsikəˈfan(t)ik` for *sycophantic* — character-for-character what Google shows.
- **The audio is a static MP3** on Google's CDN at a URL derivable from the word
  alone. Verified: `.../pronunciation/2022-03-02/audio/sy/sycophantic_en_us_1.mp3`
  → HTTP 200, MPEG layer III.

Scraping the SERP is not an option and was ruled out by measurement: a
`define sycophantic` search returns a 91 KB JS-shell (`enablejs`) containing
zero occurrences of the IPA and no `gstatic.com/dictionary` reference.

## Spec

`define <word>` prints a formatted NOAD entry and plays the pronunciation three
times.

```
$ define sycophantic
sycophantic  syc·o·phan·tic
/ˌsikəˈfan(t)ik/

  adjective
    behaving or done in an obsequious way in order to gain advantage
      "a sycophantic interview"

  DERIVATIVES
    sycophantically /ˌsikəˈfan(t)ək(ə)lē, -ˈfantik(ə)lē/  adverb

  ♫ playing 3×
```

Decisions taken up front (operator, 2026-08-20):

- **NOAD only.** No online fallback. A miss (`rizz`, `unalive` — genuinely
  absent from NOAD) prints a clean diagnostic to stderr and exits non-zero. A
  fallback source is a separate issue if it is ever wanted; note the gaps
  correlate, since both NOAD and the audio CDN trace back to Oxford.
- **Private `github.com/xianxu/tools`** is the home repo.

Parsing is best-effort over a flat string with no schema, so the parser is
built around a **no-data-loss invariant**: every non-whitespace character of the
NOAD entry must survive into the rendered output. Structure that is recognized
gets formatted; structure that is not recognized degrades to a plain paragraph
rather than being dropped. This is what keeps a best-effort parser honest
against entries nobody sampled.
